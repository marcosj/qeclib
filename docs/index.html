qeclib

A lightweight Python toolkit for building CSS quantum error-correcting circuits in Stim, injecting circuit-level noise, and exporting Detector Error Model (DEM) hypergraph Tanner structures and fixed-point test vectors for hardware (FPGA/RFSoC) and software decoders.

API Reference ↗ gf2 circ noise tanner

Pipeline Overview

1. GF(2) Logicals (gf2.py)

Row reduction, nullspace, and quotient-basis synthesis for conjugate CSS logical pairs (LX LZT = Ik mod 2).

2. Stim Circuits (circ.py)

Optimal Kempe-chain bipartite edge coloring (Δ(H) CNOT depth), space-time detector coordinates, and timeslice-svg layouts.

3. Circuit Noise (noise.py)

Tick-level injection for SI1000 and configurable 1q/2q gate, reset, readout, and idle depolarizing channels.

4. Tanner & FPGA Export (tanner.py)

Hypergraph DEM extraction, fixed-point int8/int16 LLR quantization, CSR/adjacency lists, and bit-packed syndrome vectors.

Example: Steane [[7, 1, 3]] under SI1000 (p = 0.002, 3 rounds)

Running make run packs syndrome extraction into 4 parallel CNOT layers per basis and exports the circuit-level Tanner graph and 10,000 test shots to out/:

  • Tanner matrix H: 18 detectors × 276 fault variables (881 edges; check degrees 7–79, variable degrees 1–6)
  • Logical flip mask L: 1 × 276
  • Quantized LLRs (Q4 in int8): 63 to 127 (float range 3.92 – 8.92)
  • Artifacts: out/model.json, out/vectors.npz, out/model.dem

Quickstart

pip install -r requirements.txt
make run    # generate Steane DEM, Tanner graph & FPGA vectors in out/
make docs   # rebuild HTML API docs into docs/api/
